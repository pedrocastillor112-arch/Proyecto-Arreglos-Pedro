# Sistema de Calificaciones de Estudiantes

## Descripción
Programa de consola que almacena las calificaciones de varios estudiantes en un vector (lista de Python)
y permite consultarlas, modificarlas y analizarlas mediante índices, ciclos y condiciones.
El vector inicial es `[85, 67, 92, 74, 58]` y se considera aprobado quien obtiene 70 o más.

## Objetivo
Aplicar los conceptos de arreglos y vectores del Capítulo IX de Introducción a la Programación:
almacenar, consultar, modificar y procesar un conjunto de datos usando índices y ciclos.

## Lenguaje utilizado
Python 3 (versión 3.8 o superior). No requiere librerías externas.

## Funcionalidades desarrolladas
1. Mostrar todas las calificaciones recorriendo el vector con un ciclo `for`.
2. Consultar la calificación de un estudiante mediante su índice.
3. Calcular el promedio del grupo.
4. Identificar la calificación más alta y el estudiante que la obtuvo.
5. Identificar la calificación más baja y el estudiante que la obtuvo.
6. Contar cuántos estudiantes aprobaron.
7. Contar cuántos estudiantes reprobaron.
8. Modificar una calificación indicando el estudiante y la nueva nota.
9. Mostrar el vector actualizado y recalcular promedio, aprobados y reprobados.
10. Validar las entradas del usuario con un ciclo `while` para evitar errores de índice.

## Instrucciones para ejecutar el programa
1. Instalar Python 3 desde https://www.python.org/downloads/
2. Descargar o clonar el repositorio:
   ```
   git clone https://github.com/pedrocastillor112-arch/Proyecto-Arreglos-Pedro.git
   ```
3. Entrar a la carpeta del proyecto:
   ```
   cd Proyecto-Arreglos-Pedro
   ```
4. Ejecutar el programa:
   ```
   python sistema_calificaciones.py
   ```
